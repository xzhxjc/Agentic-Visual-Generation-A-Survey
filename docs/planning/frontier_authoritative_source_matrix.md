# Frontier 权威来源矩阵

## 使用说明

本矩阵用于扩大 Agentic Visual Generation Frontier 的理论视野。来源分为三种证据状态：

- `本地全文`：已读取本地 PDF，可用于分析其章节组织和明确观点；
- `本地元数据/引用`：项目中已有书目信息或被本地综述引用，正式用于正文前仍应读取原文；
- `外部检索发现`：通过学术检索定位，尚未进入本地全文库，只用于发现方向，不能直接承担正文事实。

## 综合发现

扩大来源后，AVG Frontier 可以被理解为五个相互关联的系统能力轴：

1. `Visual Reasoning and Structured Control`：生成前和生成中的视觉推理能否形成可执行、可检查且能够约束最终结果的中间状态。
2. `Persistent and Interactive Visual Worlds`：生成结果能否成为长期存在、局部可编辑、跨视角一致并对行动作出合理响应的环境。
3. `Continual Learning and Self-Evolving Creation`：系统能否把经验转化为跨任务技能、策略、工具和个性化能力，同时避免遗忘与错误固化。
4. `Human--Agent Co-Creation in Open Environments`：系统能否在主观目标、不可信输入、外部副作用和责任约束下形成可持续的人机创作关系。
5. `Evaluation and Scientific Infrastructure`：领域能否以可复现的轨迹、压力测试和多维指标证明上述能力。

Generalist visual creation agent 是这五个方向共同汇聚的系统形态，不适合单独成为一个边界模糊的一级方向。
