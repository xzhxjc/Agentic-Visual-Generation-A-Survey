# Agentic Visual Generation: A Survey

This folder is a self-contained Overleaf package for the manuscript.

## Main file

Set `agentic_visual_generation_survey.tex` as the main document.

## Compilation

- Compiler: **XeLaTeX**
- Bibliography tool: **BibTeX**
- Bibliography database: `references.bib`

Upload the complete `overleaf_agentic_visual_generation` folder to Overleaf (or upload its contents as a ZIP), then compile the main `.tex` file.

The `sections/` directory contains all section files referenced by the main document. The ACM class and bibliography style included here are the local template files required by the manuscript.
