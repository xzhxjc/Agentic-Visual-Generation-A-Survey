# 智能体式视觉生成：技术报告与模型发布清单

## 收录与核查规则

- **时间范围：**2010--2026-08-24 期间公开的技术报告、模型卡、开源仓库和官方产品发布。
- **领域范围：**沿用论文现有章节：图像；视频与动画；3D、CAD 与世界；科学可视化；结构化文档；UI 与 Web；跨领域或统一多模态模型。
- **来源规则：**每项均需一手来源，包括作者发布的技术报告、官方模型卡或仓库、官方产品页面或官方公告。搜索结果、转载截图、泄露信息和社区昵称不能作为证据。
- **发布规则：**当研究报告与产品/API 的名称、发布日期或明确能力不同，分别记录。产品可用性不能替代实现机制说明。
- **论文使用规则：**只有条目的具体机制与正文论断相关、且已回查一手来源时，才可加入 Bib 或作为论文案例。基础模型本身不构成智能体控制证据；产品/API 只有在来源明确报告多轮状态、工具调用或执行反馈时，才列入 Agentic 或疑似 Agentic 小节。
- **来源类型：**`P` 表示一手技术报告；`O` 表示官方产品或模型发布；`R` 表示官方仓库或模型卡。尚未完成核验的候选不进入下表。

## AVG 判据与分类口径

本文将智能体式视觉生成（AVG）限定为目标驱动的闭环视觉创作：系统保留可访问的任务相关状态，且运行时观测、验证结果、执行结果或交互历史以可追踪的方式改变后续视觉创作动作。模型名称、内部多步采样、工具 API、带有 “Agent” 的产品名称，以及用户多轮输入都不能单独证明这一行为。

| AVG 分类 | 具体判据 |
|---|---|
| **明确具有 AVG 式闭环能力** | 一手来源明确给出创作轨迹，并能定位到演化中的产物或任务状态、运行时证据、发生变化的后续动作，以及它们之间的关系。 |
| **明确不属于 AVG** | 来源描述生成器、编辑器、表征模型、固定语法/运行时或单次输入输出操作，且没有任务级“观测—后续动作”决策过程。 |
| **现有来源无法判定** | 产品可能支持多步辅助、代码执行或智能体工作流，但当前记录的一手来源没有提供足够的轨迹级证据。 |

截至本次核查，135 个条目中：**明确具有 AVG 式闭环能力：5；明确不属于 AVG：115；现有来源无法判定：15。** 此结论只针对表中记录的一手来源，不评价这些模型能否在其他系统中充当 AVG 的生成器或执行器。
